# Screenshots

Drop these PNGs here with exactly these names; the main README already points at them.

| File | What to capture |
|---|---|
| `panel-review-dark.png` | The panel in dark mode on the review step, with colours listed and the **Add N variables** button visible. The hero image. |

How to take them: open a Kirki editor page (`?action=kirki`), open the panel, import
from Figma or paste a chart, then press **⌘⇧4 then Space** on macOS and click the panel
to capture just that window. Crop out anything private.
